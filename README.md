# متجر نانو بايت تكنولوجي — NANO BYTE Store

**الرابط:** https://nanobyte-store.pages.dev — **لوحة التحكم:** https://nanobyte-store.pages.dev/admin/

متجر إلكتروني لمحل **نانو بايت تكنولوجي** في أم درمان (الشهداء — عمارة الهانم).
يفتح على الهاتف كأنه تطبيق تسوق، والطلب يتم عبر واتساب.

## التقنية

| الجزء | الأداة | السبب |
| --- | --- | --- |
| الواجهة | Next.js 16 + TypeScript + Tailwind CSS 4 | تُصدَّر كملفات ثابتة (static export) |
| الاستضافة | Cloudflare Pages (الخطة المجانية) | مجانية ومسموح فيها الاستخدام التجاري |
| قاعدة البيانات، الدخول، الصور | Supabase (الخطة المجانية) | Postgres + Row Level Security |

الموقع ما فيه سيرفر خاص: المتصفح يكلّم Supabase مباشرة بالمفتاح العام (anon) فقط،
وكل الصلاحيات محمية داخل قاعدة البيانات بـ Row Level Security.
المفتاح السري (service_role) لا يوضع أبداً في الموقع.

## الصفحات (المرحلة 2)

- `/` الرئيسية: بانرات، أقسام، وصل حديثاً، عروض، صيانة، تواصل
- `/categories/` كل الأقسام
- `/shop/` البحث والفلاتر والترتيب (`?q= &cat= &brand= &cond= &cpu= &gen= &ram= &sto= &min= &max= &stock=1 &offers=1 &sort=`)
- `/p/?id=NB-0001` صفحة المنتج + طلب عبر واتساب
- `/cart/` السلة + معاينة رسالة واتساب
- `/services/` طلب صيانة عبر واتساب
- `/contact/` العنوان والأرقام والخريطة

الكتالوج كامل يُحمَّل مرة ويُحفظ في الهاتف، فالبحث والفلاتر تشتغل فوراً حتى مع إنترنت ضعيف،
وتتحدث البيانات في الخلفية.

## لوحة التحكم `/admin/`

- الدخول بالإيميل وكلمة السر. التسجيل مقفول إلا للإيميلات المضافة من صفحة «الموظفين».
- **موظف**: إضافة وتعديل المنتجات والصور، الأسعار، الكميات، الإخفاء/الإظهار، العروض.
- **مدير**: كل ما سبق + حذف المنتجات، الأقسام، معلومات المتجر ورقم واتساب، تغيير كل الأسعار بنسبة، الموظفين.
- الصور تُضغط في الهاتف قبل الرفع (WebP حوالي 1280px + صورة مصغرة).
- قاعدة البيانات: `supabase/migrations/` — الحماية بـ Row Level Security ومجرّبة على المشروع الحقيقي.
- `.github/workflows/keep-supabase-awake.yml` يمنع توقف Supabase المجاني بعد أسبوع بدون زيارات.

## التشغيل المحلي (للمطوّر)

```bash
npm install
cp .env.example .env.local      # ضع بيانات Supabase
npm run dev

# معاينة ببيانات تجريبية بدون Supabase:
NEXT_PUBLIC_DEMO=1 npm run dev
```

البناء: `npm run build` ← الناتج في مجلد `out/`.

النشر (Cloudflare Pages، مشروع `nanobyte-store`، رفع مباشر):

```bash
npm run build
npx wrangler pages deploy out --project-name nanobyte-store --branch main
```

تغيير المنتجات والأسعار والإعدادات من لوحة التحكم لا يحتاج نشر: يظهر للزبائن فوراً.
